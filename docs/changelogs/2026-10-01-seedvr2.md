# 2026-10-01 — SeedVR2 enhancement preset

Video → Enhance now includes a bundled **SeedVR2 Video Upscale — 8GB** workflow.
Startup adds the preset if missing; user edits and disabled presets survive
subsequent launches. Portable backend builds include the same graph.

The preset uses SeedVR2 3B Q4_K_M with CPU offload, BlockSwap and VAE tiling.
Output resolution and frames per batch are editable in Enhance. Source audio,
frame rate and aspect ratio are preserved; no text prompt is required.
API-format and visual ComfyUI examples are included for manual import/editing.
Enhancement metadata keeps the preset out of scene-generation defaults and
selectors, including when the API example is imported manually.

ComfyUI must have the SeedVR2 custom nodes, their dependencies and the DiT/VAE
weights installed. Calliope does not install or download them at startup.

Validation: 695 backend tests passed; frontend checks and production build
passed. A real ComfyUI render with SeedVR2 2.5.24 on an 8GB RTX 4060 Laptop GPU
upscaled five frames to 1280×720 in 41 seconds. Frame count, 13 fps, clip duration
and audio were preserved. Both downloaded model files passed SHA-256 validation.
